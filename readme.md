# Data and Analytics Platforms
## Objectives: Using this project I want to demonstrate my proficiency and skills in Data Engineering, Data Analytics and Big Data problems.
## Planing: 
* In First phase, I'll design and implement only batch data solutions with maximum possible modularity and industry grade efficiency, best practices.
* In next phase, I'll design and implement low-latency stream data processing with touch of big data.
* Next, I'll design and implement next generation data engineering solution by solving problems like scaling data science based analytics.
* Throughout this process I'll leverage cloud independent, cutting edge tools and technologies and implement multi frameworks.
* I hope this project will be in planning and development phase till eternity!
